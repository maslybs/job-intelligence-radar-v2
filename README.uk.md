# Job Intelligence Radar

**Мова / Language:** [Українська](README.uk.md) | [English](README.md)

Радар для пошуку **вакансій** і **потенційних клієнтів** на Cloudflare Workers, D1, Workflows та Workers AI. Ви встановлюєте власну копію, вибираєте джерела й налаштовуєте критерії під свій досвід. Відкритий код, ліцензія **MIT**.

[![Deploy to Cloudflare](https://deploy.workers.cloudflare.com/button)](https://deploy.workers.cloudflare.com/?url=https://github.com/maslybs/job-intelligence-radar-v2)

**Без термінала:** натисніть кнопку, увійдіть у власні акаунти Cloudflare та GitHub, виберіть назви ресурсів і розгорніть застосунок. Шаблон використовує окремі Worker і D1, Workers AI та Workflows, зі зразковим погодинним пошуком. Він не використовує акаунти, базу чи секрети автора.

**Важливо:** стартовий профіль **вигаданий**. У зразку є три відкриті джерела вакансій, але Telegram, пошук клієнтів, Reddit/DOU-браузер та доступ до локального комп’ютера вимкнені. Замініть профіль, перш ніж використовувати оцінки як свої рекомендації.

## Документація українською

## Як працює радар

**Пошук роботи (`jobs`).** Радар отримує оголошення з відкритих API, RSS та сайтів із підтримуваними інтеграціями, зберігає їх у D1 та оцінює відповідність **вашому реальному досвіду**. Враховуються роль, технології, країна, формат роботи та оплата. Оцінка — орієнтир, **не гарантія співбесіди чи найму**.

**Потенційні клієнти (`leads`).** Окремий профіль описує ваші послуги, підтверджений досвід, бажані типи компаній та критерії платоспроможного попиту. Питання в спільноті не означає, що автор шукає підрядника. **Автоматичних небажаних особистих повідомлень немає.** Цей напрямок у типовому шаблоні вимкнено.

## Що доступно після встановлення

| Компонент | Типова поведінка |
| --- | --- |
| Cloudflare Worker | Власний застосунок за URL `*.workers.dev` |
| D1 | Власна база вакансій, статусів і запусків |
| Workflows | Фонова обробка |
| Workers AI | AI-оцінювання з лімітом запитів |
| Cron | Зразковий запуск раз на годину |
| Inbox | Захищений паролем список з українськими вкладками |
| Telegram, Reddit/DOU, OneAIHUB | Вимкнено до явного налаштування |

Cloudflare може тарифікувати використання D1, Workers AI та Workflows — контролюйте квоти й витрати.

## Паролі та особисті дані

У Cloudflare **Secrets** задайте:

- `INBOX_PASSWORD` — власний надійний пароль для входу в Inbox.
- `ADMIN_TOKEN` — **окремий** випадковий токен для адміністративного API.

Без `INBOX_PASSWORD` увійти до Inbox не можна. Без `ADMIN_TOKEN` адміністративні запити блокуються. Не публікуйте паролі, Telegram-токени, особисті критерії чи справжнє CV у GitHub.

Для конфігурації профілю через Cloudflare Builds передбачено **приватну змінну часу збірки** `RADAR_CONFIG_JSON`, яка не повинна потрапляти в репозиторій. Деталі — у [посібнику налаштування](docs/configuration.uk.md).

## Локальна розробка

Потрібні Node.js 20+ і npm:

```bash
npm ci
npm run setup
# Відредагуйте приватний config/radar.config.json
npm run config:generate
npm run ci
npm run build:check
npm run test:runtime
```

Файли `config/radar.config.json`, `src/config/radar.generated.js` і `.dev.vars` ігноруються Git. Не додавайте їх до публічних комітів.

**Стан проєкту:** є тести, Cloudflare Runtime smoke, суха збірка Wrangler та перевірка міграцій на порожній D1. Наскрізне встановлення через кнопку в сторонньому Cloudflare-акаунті ще не підтверджено. Перегляньте [обмеження сумісності](docs/feature-parity.md) та [попередження щодо dev-залежностей](README.md#development-dependency-advisories).
